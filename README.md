# Lumen — LandingPage8

A polished single-page marketing site for a modern SaaS product. The page is a
fully static frontend (`index.html` + `styles/` + `scripts/`) that includes a
hero section, a features grid, and a fully validated contact form. Submissions
are POSTed to a configurable JSON endpoint (default `/api/contact`); a
reference backend handler lives in [`server/contact-handler.example.js`](./server/contact-handler.example.js).
