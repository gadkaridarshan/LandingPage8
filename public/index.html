Project structure

Site folders at a glance

A quick map of the folders shipped with this landing page so you can see how the pieces fit together.

  • public

    Static entry point — the rendered HTML and shared stylesheet.

  • scripts

    Vanilla JavaScript for navigation and contact form behavior.

  • styles

    Modular CSS for hero, features, contact, and shared base tokens.

  • server

    Reference backend handler for receiving contact form submissions.

  • src

    TypeScript source for type-safe utilities shared across the project.

  • .helix

    Helix workspace metadata — product context and Kanban story board.

  • .vscode

    Editor workspace settings — preferred Helix model and tooling defaults.
